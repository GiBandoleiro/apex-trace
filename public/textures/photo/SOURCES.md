# Photographic PBR surfaces

The color, OpenGL normal, and roughness maps in this directory were derived
from [Poly Haven](https://polyhaven.com/license) assets under **CC0**. Images
were resized to 512 or 1024 pixels and encoded as WebP for browser delivery.

| Game surface | Poly Haven asset |
| --- | --- |
| Asphalt | [Aerial Asphalt 01](https://polyhaven.com/a/aerial_asphalt_01) |
| Dirt | [Dirt Aerial 02](https://polyhaven.com/a/dirt_aerial_02) |
| Grass | [Grass Ground](https://polyhaven.com/a/grass_ground) |
| Gravel | [Gravel Ground 01](https://polyhaven.com/a/gravel_ground_01) |
| Concrete | [Concrete Floor Worn 02](https://polyhaven.com/a/concrete_floor_worn_02) |
| Sand | [Aerial Sand](https://polyhaven.com/a/aerial_sand) |
| Snow | [Snow 02](https://polyhaven.com/a/snow_02) |
| Basalt | [Aerial Rocks 01](https://polyhaven.com/a/aerial_rocks_01) |
